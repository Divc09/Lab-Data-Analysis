# SmartFitter v2 improvement backlog

2026-10-14. This is a proposal list, not a claim that every item is a reproduced bug. **Confirmed** means the current source or browser run directly demonstrated the problem; **candidate** means it needs a focused reproduction or design decision before implementation. Effort is rough: S = localized, M = several components, L = state/data-model change. Priorities reflect risk to saved analysis and Div's stated comparison, map, speed, and clutter concerns.

## Working principles

Keep measured time axes, explicit units, per-detector provenance, and physically faithful map geometry. Avoid deleting options or keyboard shortcuts as a decluttering shortcut. Separate saved-data/software validation from claims about the experiment. LabPlot's [current feature list](https://labplot.org/pages/features/) informed the axis, template, cursor, and autosave proposals; the source-specific priorities above come from this checkout and the real-file audit.
